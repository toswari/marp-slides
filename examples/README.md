## How to Use Examples

1. **Identify the style** — What category matches your request?
2. **Read 2-3 examples** — Note the composition, spacing, visual density
3. **Match the quality bar** — Use similar structure and element choices
4. **Adapt components** — Pull specific cards, charts, or layouts as needed
